# ConferenceBox

Multi-conference CMS. Update from [TourConf](https://github.com/RStankov/it-tour).

### Installation

```
./bin/dev/boot
```

### Running

```
./bin/dev/start
```

### Call for papers

Events can run their call for papers in-app: speakers submit proposals, reviewers score them and accepted proposals become sessions. See [docs/cfp.md](docs/cfp.md) for the workflow and the proposal state diagram.
